# 1. Roles Module Overview

The Falcon One Roles Module provides a centralized Enterprise Role-Based Access Control (RBAC) platform for managing users, roles, permissions, policies, authentication rules, authorization, security governance, and access control across the Falcon One Business Operating System.

The Roles Module serves as the centralized enterprise Identity and Access Management (IAM) platform.

Every permission shall be granted through centralized role-based policies.
